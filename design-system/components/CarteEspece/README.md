# Carte espèce

Carte du catalogue : signature voronoï de l'espèce en vignette, puis famille et habitat (`label`), nom scientifique (`card-title`, italique), nom commun, profondeur et température (`data`).

- Toutes les cartes d'une grille ont la même structure et la même hauteur ; le règne se lit dans la vignette et l'étiquette, pas dans la forme de la carte.
- Vignette : `radius-s` ; carte : `radius-card`, aplat `surface`, sans bordure ni ombre.
- Au survol, la signature réagit (les graines s'écartent puis reviennent).
- Entrée en cascade, déplacement avec dépassement quand un filtre change l'ordre.
