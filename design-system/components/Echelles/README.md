# Échelles

Le même champ voronoï lu à quatre densités : macro (matière de fond), méso (formes lisibles), micro (signature d'espèce), nano (une cellule devient un composant).

L'échelle se règle par le nombre de cellules visibles (`density-macro`, `density-meso`, `density-micro`, `density-nano`), jamais en agrandissant un motif. Garder la même graine d'une échelle à l'autre : on doit sentir qu'on zoome dans le même champ.

- Macro : `vein-hair`, dérive lente (`live`).
- Méso : rayon `radius-s`, réaction au curseur (`interactive`).
- Micro : 3 à 12 cellules, voir Signature.
- Nano : `Banbiom.cellPath`, voir Cellule et Bouton.
