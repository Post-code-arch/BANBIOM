# Étiquette

Étiquette-mot : un mot ou deux dans une forme. La forme dit le règne : parallélogramme incliné de 14° pour la Faune, pilule pour la Flore.

- Pleine (`cobalt` ou `lagoon`) pour une action ou un règne actif ; contour (`ink`, 1,5 px) pour un filtre ou une catégorie.
- Paire : deux étiquettes accolées séparées par `vein-fine`, comme deux cellules voisines (« Explorer / → »).
- Texte en Geologica 400, jamais en capitales.
- À l'appui, l'étiquette se tasse (échelle 0,94) puis revient avec rebond.
