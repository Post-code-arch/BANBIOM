# Graine et jonction

La graine est le point qui engendre une cellule : c'est la donnée elle-même. Sa position peut valoir une mesure (voir Signature), sa couleur un statut (`iucn-*`).

La jonction, point de rencontre de trois veines, représente une connexion. Elle sert d'icône au site et de point de focus.

- Graines visibles seulement à l'échelle méso et micro, et seulement quand elles portent une donnée.
- Couleur de graine : uniquement les tokens `iucn-*`, jamais décorative.
