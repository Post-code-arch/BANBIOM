# Veine

Le vide du système : l'espace entre deux cellules. Il a cinq largeurs (`vein-hair` à `vein-river`) et sa propre couleur, celle du fond sur lequel les cellules sont posées.

La veine porte du sens : une veine fine relie, une veine large sépare. Dans une carte macro, l'épaisseur de la veine entre deux espèces dit leur parenté (même famille `vein-hair`, autre embranchement `vein-river`).

- La largeur est exacte et constante le long de la veine (cellules rétrécies de la moitié de la veine).
- Sous le curseur, les veines s'élargissent : le vide s'ouvre.
- En interface, une veine seule fait un séparateur (`vein-fine`).
