# Signature

La signature est l'empreinte voronoï d'une espèce à l'échelle micro. Ses graines sont placées par les données :

- position horizontale : plage de température (5 à 35 °C) ;
- position verticale : plage de profondeur (échelle en racine, de 0 à 1 000 m) ;
- nombre de cellules : taille maximale ;
- forme et couleur : le règne.

Deux espèces écologiquement proches ont des signatures proches (ici les deux phanérogames). Le tirage est déterministe : une espèce garde toujours la même signature. Utiliser `Banbiom.seedsFromSpecies(espece)` comme option `seeds` de `Banbiom.field`.
